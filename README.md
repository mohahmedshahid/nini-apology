# I'm Sorry Nini 💗

A small pink apology website made as a single-page static site.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages settings.

The website uses Google Fonts when internet access is available. It still works without them using fallback fonts.
